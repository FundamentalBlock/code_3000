# Security Policy

## Intended Users

This repository is intended for personal academic use by the repository owner (Ethan) as a student in CSE 3000 at the University of Connecticut. Instructors or teaching assistants may also view the repository for grading purposes.

## Risk Assessment

The content of this repository consists of course notes and assignments. The security risk of this material falling into the wrong hands is relatively low, as it does not contain sensitive personal data, credentials, or production code. The primary concern would be academic integrity: if other students accessed this repository and submitted the work as their own, it could constitute a violation of UConn's academic integrity policy. There is no financial, personal safety, or infrastructure risk associated with this content.

## Security Measures

Because the risk profile of this repository is low, no advanced security mechanisms (such as a CODEOWNERS file or pull request rulesets) have been implemented. The repository is **public** on GitHub, which is acceptable given that it contains only personal coursework with no sensitive data, credentials, or critical code. The main academic integrity concern is acknowledged above, and students are expected to adhere to UConn's academic integrity policy independently of any technical restrictions.
